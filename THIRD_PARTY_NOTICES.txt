Nova-1B inference release preparation
Developer: INSIGHTNOVA

The gdnh2 architecture and cached decoding implementation were adapted from the
Nova-1B model code. SOURCE_PROVENANCE.json records the input source hashes.
The release wrapper/exporter separates inference from the post-training pipeline.

External dependencies (installed separately; their sources are not bundled):
- OLMo-core: https://github.com/allenai/OLMo-core
  pinned revision 92870a33c3fee060d57c3faec52b0b369ece85a6
- Flash Linear Attention: https://github.com/fla-org/flash-linear-attention
  flash-linear-attention 0.5.2, fla-core 0.5.2
- Transformers: https://github.com/huggingface/transformers (4.57.6)
- PyTorch: https://github.com/pytorch/pytorch
- safetensors: https://github.com/huggingface/safetensors
- FlashAttention, when selected: https://github.com/Dao-AILab/flash-attention
